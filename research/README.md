# Research Notes

This directory holds human-written research notes for firmware interoperability.

The goal is to capture:

- public community observations
- repo and tool findings
- hypotheses about safe retained cohorts
- open questions that still need validation

These notes are intentionally markdown-first rather than machine-readable.

## Notes

- `bootchain-interoperability.md` — retained-cohort hypotheses for mixed
  firmware updates.
- `cos17-beta-signing-and-abl.md` — ColorOS 17 beta (`ossi`) review: ABL
  `efisp` removal, QTI+OEM dual signing, and AVB rollback movement against
  the prior A17 beta and the ColorOS 16 builds.
